# AI Spend Audit

AI Spend Audit is a SaaS-style web application that helps startups analyze AI tool spending and discover cost optimization opportunities.
## Day 1
## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Supabase

## Run Locally

